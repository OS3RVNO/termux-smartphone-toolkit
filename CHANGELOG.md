# Changelog

All notable changes to Termux Smartphone Toolkit are documented here.

## 3.0.0 — 2026-08-16

- Added the interactive Termux Smartphone Hub.
- Added the Zsh and Starship mobile shell configuration.
- Added configurable battery notifications from 1% to 100%.
- Added XFCE startup through Termux:X11.
- Added clipboard, text-to-speech and QR-code tools.
- Added network checks, authorized LAN discovery and temporary file sharing.
- Added FFmpeg video compression.
- Added Debian PRoot integration.
- Added configuration backups that exclude SSH keys and secrets.
- Added a Python QR fallback for Google Play repositories without `qrencode`.
